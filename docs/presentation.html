Επισκόπηση

Τι Υλοποιήσαμε

1. Αρχιτεκτονική Πλατφόρμας

Multi-node Kubernetes cluster με ξεχωριστό service ανά ρόλο. Manager ως κεντρικός orchestrator, 3 worker nodes για inference, shared object storage.

2. Ενεργειακή Παρακολούθηση

Διερεύνηση RAPL → αποτυχία σε Docker containers → εναλλακτική λύση με Kepler / eBPF. Deployment ως DaemonSet σε κάθε κόμβο.

3. Μοντέλο Ισχύος & Άνθρακα

Γραμμικό μοντέλο υπολογισμού ενέργειας ανά inference job. Προσομοίωση ετερογενούς carbon intensity ανά κόμβο.

4. PostgreSQL Persistence

Σχεδιασμός και deployment βάσης δεδομένων. Αποθήκευση ιστορικού jobs με μετρικές latency, energy_joules, carbon_gco2.

5. Round-Robin Scheduler

Thread-safe κατανομή εργασιών στους 3 workers. Κεντρικός Manager με lock-based index για ταυτόχρονες αιτήσεις.

6. Web Dashboard

Real-time UI: κατάσταση κόμβων, φορτωμένο μοντέλο, avg energy & carbon intensity ανά worker, πλήρες job history.

Ενεργειακή Παρακολούθηση

RAPL → Kepler / eBPF

RAPL

✗ Απέτυχε
  • Μετρητής ενέργειας μέσω /sys/class/powercap/intel-rapl/
  • Αρχικά φάνηκε να λειτουργεί — αρχείο προσβάσιμο μέσα στα containers
  • Πρόβλημα: ο μετρητής παρέμενε στατικός — ίδια τιμή πριν και μετά το inference
  • Αιτία: Docker containers χωρίς πλήρη MSR πρόσβαση δεν λαμβάνουν updates από τον host kernel

Kepler + eBPF

✓ Λειτουργεί
  • CNCF open-source — Kubernetes Efficient Power Level Exporter
  • Χρησιμοποιεί eBPF probes για per-container CPU time από τον host kernel
  • Λειτουργεί ανεξάρτητα από Docker isolation — βλέπει απευθείας τα cgroup events
  • Deployment ως DaemonSet (1 pod / κόμβο), privileged: true, hostNetwork: true
  • Εκθέτει Prometheus metrics: NODE_IP:9102/metrics
  • Μετρική: kepler_container_bpf_cpu_time_ms_total

Μοντέλο Ισχύος

Βάση: energy-proportional computing (Barroso & Hölzle, 2007)

Ejob = (Δtcpu / 1000) · Pcore
Pcore = TDP / Ncores = 120W / 8 = 15 W

Scheduling

Round-Robin Scheduler

Αλγόριθμος

_rr_index = 0
_rr_lock = threading.Lock()

def _next_worker():
  with _rr_lock:
    host = WORKERS[_rr_index % 3]
    _rr_index += 1
  return host
  • Thread-safe — Lock για ταυτόχρονα HTTP requests
  • Κατανέμει ισόποσα: A → B → C → A → ...
  • Αγνοεί φόρτο, ενέργεια, carbon intensity — baseline αλγόριθμος
